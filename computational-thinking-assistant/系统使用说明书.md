# 计算思维课程助手系统 - 使用说明书

本说明书指引用户（包括学生用户、教师以及管理员）如何操作并使用计算思维辅助系统的各个功能模块。

## 1. 账号注册与登录

本系统通过 JWT 令牌鉴权，保护个人问答及学习记录数据的安全性。

1. **注册新账号**：
   - 首次使用需要访问 `http://localhost:5173/register` 页面填写基本信息进行注册。
   - 需要提供对应的 `登录名 (username)` 和 `密码`，选填昵称和邮箱。
   - 提交通过后会自动提示注册成功并跳转至登录页。
2. **系统登录**：
   - 访问 `http://localhost:5173/` 首页进行登录，如果开启“记住密码”功能，可在数天内免密码自动进入。
   - 系统中存在不同权限设置，包括“普通学生用户”与“系统管理员”。

## 2. 聊天与智能问答功能

作为核心功能模块，其主界面通常包含左侧“历史会话列表”，以及中间的“对话框”。

1. **多会话管理**：
   - 点击左上角（或侧边栏）的 `[+ 新建会话]` 功能，可以随时开启一轮全新的问答聊天。
   - 您可以点击已有会话进行查阅、修改会话标题来归档当前聊天的主题，或者删除该会话记录。
2. **发起提问**：
   - 在底部的输入框内键入您的技术或课程理论问题，按下 `Enter` 键即可发送。（使用 `Shift + Enter` 可执行换行操作）。
   - AI 回复时实现了实时“打字机”流式效果。
3. **RAG 检索增强智能回复**：
   - 当您的提问涉及《计算思维》课程特定内容时，系统后台先自动前往本系统的 ChromaDB 知识库进行检索。
   - 对话流返回的数据如果参考了知识库中的文段，会有更高的契合度与准确性。

## 3. 代码智能分析功能

对于学习编程算法的同学，代码分析能为计算思维学习提供可视化帮助。

1. **提交代码**：
   - 点击顶部导航栏切换至【代码分析】模块。
   - 将您在编写过程中的 Python 语言代码片段粘贴进入左侧的代码输入工作区。
2. **执行静态分析**：
   - 提交后，系统将使用内部的 `AST 分析服务` 解析代码复杂度、变量声明状态。
   - 借助于 AI ，系统为这段代码生成的评分、优化建议，以及是否存在“常见错误模式”（如逻辑错误边界越界等）。
3. **深入问答**：
   - 针对当前代码出现的问题，可以进一步向右侧挂载的 AI 继续提问，实现“聚焦式答疑”。

## 4. 学习数据与报告分析 (数据看板)

本模块辅助学生或教师查验一段周期内的学习行为轨迹。

1. **学习概览大屏**：
   - 在顶部导航栏点击【学习分析】。
   - **概览面板**会展示您的总计提问数、累计活跃天数、代码测试覆盖等基本指标。
2. **活跃度与趋势可视化**：
   - 面板的**活跃度热力图**以及**趋势折线图**记录了大家每天与 AI 的交互频次，帮助您复盘并管理学习计划。
3. **薄弱点与错误归因**：
   - 系统分析后台通过收集您平时的代码分析漏洞报错、提问问题聚类，在“薄弱点分析图”中展现。可以通过它发现自身薄弱的计算思维部分（如：算法思维薄弱还是数据逻辑抽象薄弱）。
4. **生成与导出 PDF 报告**：
   - 您可以点击右上方的【导出学习报告(PDF)】，利用报告插件一键自动将图表与统计文字存留到本地设备中。

## 5. 知识库管理功能

> **注意**：部分知识库管理的上传删除权限更适合于教师/管理员用户，但依据系统实际角色权限开放程度可能会所有差别。

1. **浏览知识文件库**：
   - 导航至【知识库】页面，通过列表您可以清楚看到系统中当前搭载了哪些教材章节的基础课件（Markdown 或文本）。
2. **挂载/上传新知识**：
   - 使用文件上传按钮导入新的教学大纲或教程，点击保存后系统后台会自动执行“分块切割（Chunking）-> 向量模型 Embedding -> 载入数据库”的全流程。
3. **删除陈旧文档**：
   - 知识结构需要更新时可以对部分行点击【删除】释放向量数据库空间。

## 6. 用户管理与系统状态 (管理员专属)

该功能区默认对普通学生隐藏。拥有 `admin` 权限的用户可以看到顶部带有【用户管理】或者【后台面板】的菜单项。

1. **管理用户状态**：
   - 阅览所有已注册人员。
   - 对部分异常刷借口的用户执行**封禁（冻结）账号**或**删除账号**。
2. **重置权限**：
   - 支持通过管理员更改某用户为助教或另一管理员。
3. **全域数据统计视图**：
   - 管理员身份下的学习报表会拥有更广泛的全站数据观测权。
