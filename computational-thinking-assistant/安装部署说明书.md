# 计算思维课程助手系统 - 安装部署说明书

本说明书详细介绍如何在本地或服务器环境中从零开始部署“计算思维辅助系统”。本系统采用前后端分离架构，其中后端基于 Python Flask，前端基于 Vue 3 + Vite。

## 1. 环境准备

在开始部署之前，请确保您的服务器或本地计算机已经安装了以下环境：

- **Python**: 3.11 或更高版本（必须，涉及到相关 AI 框架支持）
- **Node.js**: 18.0 或更高版本
- **npm**: 9.0 或更高版本
- **Git**: 用于拉取项目代码
- **磁盘空间**: 至少准备 2GB 空闲空间（其中包含了文本向量化模型 Sentence Transformers 约 400MB 以及本地 ChromaDB 数据库的空间）

## 2. 获取代码
方法一：
使用 Git 工具将项目代码克隆至本地，并进入项目目录：

```bash
git clone <项目仓库地址>
cd computational-thinking-assistant
```

项目主要分为两部分：
- `backend/` 目录存放后端 Python Flask 项目代码。
- `frontend/` 目录存放前端 Vue.js 项目代码。

方法二：
直接在论文系统下载相关源码

## 3. 后端服务部署

后端主要负责核心的 Web API、大模型访问（LLM）、知识库检索（RAG）、基于 AST 树的代码检查等。

### 3.1 创建并激活 Python 虚拟环境

进入后端项目所在目录：

```bash
cd backend
```

强烈建议使用 Python 的虚拟环境管理依赖以免污染全局环境：

- **Windows**:
  ```bash
  python -m venv venv
  venv\Scripts\activate
  ```

- **macOS / Linux**:
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3.2 安装依赖包

在激活的虚拟环境中，执行如下命令安装必需的库：

```bash
pip install -r requirements.txt
```

> **注意**：由于项目依赖了 `sentence-transformers` 等 AI 库，下载过程可能较慢。另外，第一次启动或执行时会自动下载 HuggingFace 的词嵌入模型文件（约 400MB），请确保网络畅通。

### 3.3 配置环境变量

在 `backend` 根目录下创建一个 `.env` 文件（可以直接复制参考项目结构中可能存在的示例文件），并配置以下项：

```env
# Flask 应用配置
SECRET_KEY=your-secret-key-change-in-production-12345678
DEBUG=True
HOST=0.0.0.0
PORT=5000

# 数据库配置（不填则默认使用 backend/data/app.db SQLite）
# DATABASE_URL=sqlite:///data/app.db

# OpenAI API 配置 (用于对接大语言模型获取 AI 回复)
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-3.5-turbo

# 聊天生成配置
ENABLE_STREAMING=True
MAX_CONTEXT_MESSAGES=10
TEMPERATURE=0.7
MAX_TOKENS=2000

# RAG 配置 (检索增强设定)
ENABLE_RAG=True
RAG_TOP_K=3
```

### 3.4 数据库初始化与服务启动

依赖和环境变量配置完成后，启动 Flask 应用程序：

```bash
python app.py
```

在**首次启动**时，应用代码检测到数据库不存在，会自动执行建表操作（初始化 SQLite 和 ChromaDB 向量数据库相关结构）。

若看到类似 `Running on http://127.0.0.1:5000` 的输出，说明后端已经成功启动运行。默认端口为 5000。

### 3.5 导入初始文档知识库（可选但在 RAG 场景推荐）

若想填充系统的 RAG 基础，可将项目附带的（或自己的）说明文档放入 `backend/data/knowledge` 文件夹下，然后新开一个终端（需在虚拟环境中）运行批量导入脚本：

```bash
cd backend
python scripts/import_knowledge.py
```

这会自动进行文件预处理，将内容分块并插入到 ChromaDB 当中。

## 4. 前端服务部署

前端主要负责系统界面展示、状态管理和与后端进行 API 以及流式数据 (SSE) 交互。

### 4.1 安装前端依赖

重新打开一个终端窗口，将路径切换到 `frontend` 目录：

```bash
cd ../frontend
```

执行如下命令安装所有 Node.js 依赖：

```bash
npm install
```

### 4.2 配置前端环境变量（可选）

如果后端接口不是默认的 `http://localhost:5000/api`，可以在 `frontend` 目录下新建一个 `.env` 文件来重写 API 地址：

```env
VITE_API_BASE_URL=http://localhost:5000/api
```

### 4.3 启动前端开发服务器

确保在 `frontend` 目录，通过 Vite 启动开发：

```bash
npm run dev
```

成功启动后，控制台会输出本地访问地址：`http://localhost:5173`。

### 4.4 生产级别构建（附加）

如果您是在服务器上线部署，可以使用以下命令打包成静态文件：

```bash
npm run build
```
打包后生成的 `dist` 目录内文件即可部署到 Nginx 或其他静态资源服务器中。

## 5. 部署过程常见问题

1. **`sentence-transformers` 无法下载模型**
   检查网络是否代理，可尝试手动在 HuggingFace 下载对应模型放置到本地。

2. **数据库初始化报错**
   确保 `backend/data` 目录有写入权限；并检查 `requirements.txt` 内所需的 Flask-SQLAlchemy 版本是否匹配。

3. **前端跨域错误 (CORS)**
   确保后端的 `app.py` 中以及 `Flask-CORS` 初始化处对前端开发环境端口（5173）进行了 CORS 放行配置。

4. **流式问答卡顿或者无反应**
   检查 `.env` 文件中的 `OPENAI_API_KEY` 是否有效并拥有额度；如果不需要代理或者正在使用国内第三方 API，请同步修改 `OPENAI_BASE_URL`。
