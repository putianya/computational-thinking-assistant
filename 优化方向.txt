这段代码展示了如何监控和限制 AI API 的资源消耗，主要有两个优化点：

1. Token 使用统计 (usage)
作用：

实时查看每次 API 调用消耗的 Token 数量
成本控制：按 Token 计费的模型（如 GPT-4）可以精确计算费用
性能监控：输入过长会导致响应变慢，通过统计可以发现问题
2. 限制输出长度 (max_tokens)
作用：

防止超支：避免模型生成过长回复导致费用失控
提升响应速度：生成更少内容 = 更快返回结果
强制简洁：配合 prompt（如"用 50 字介绍"）可以控制输出质量
3. 与您原代码的对比
特性	原代码	优化代码
Token 统计	❌ 无	✅ 显示详细用量
输出限制	❌ 无限制	✅ max_tokens=100
错误处理	✅ 重试机制	❌ 无
建议：结合两者优点，在 call_ai_with_retry 中添加统计功能。

4. 实际应用场景
预算管理：设定每日 Token 上限，超出后停止调用
调试优化：发现某些 prompt 消耗过多 Token，及时精简
A/B 测试：对比不同模型（如 gpt-4o vs gpt-4o-mini）的成本差异



from openai import OpenAI
from dotenv import load_dotenv
import os

load_dotenv()

client = OpenAI(
    api_key=os.getenv("GITHUB_TOKEN"),
    base_url="https://models.inference.ai.azure.com"
)

def call_ai_with_stats(messages, model="gpt-4o-mini", max_tokens=None):
    """调用 AI 并显示 Token 使用统计"""
    
    response = client.chat.completions. create(
        model=model,
        messages=messages,
        max_tokens=max_tokens  # 限制最大输出长度
    )
    
    # 提取使用信息
    usage = response.usage
    content = response.choices[0].message.content
    
    # 打印统计
    print("=" * 50)
    print(f"📊 Token 使用统计:")
    print(f"  输入 tokens: {usage.prompt_tokens}")
    print(f"  输出 tokens: {usage.completion_tokens}")
    print(f"  总计 tokens: {usage.total_tokens}")
    print("=" * 50)
    
    return content

# 使用示例
messages = [
    {"role":  "user", "content": "用 50 字介绍 Python"}
]

result = call_ai_with_stats(messages, max_tokens=100)  # 限制输出
print("\nAI 回复:", result)
